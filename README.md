# Tony-Stark
Aplicación web que reconoce gestos de las manos en tiempo real mediante la cámara. Permite controlar animaciones 3D, partículas y mensajes sin contacto físico.

# ✋ Hands

##  ¿Qué hace?
Detectar gestos de las manos en tiempo real. Dependiendo del gesto, genera efectos visuales como animaciones 3D, partículas y mensajes en pantalla.
